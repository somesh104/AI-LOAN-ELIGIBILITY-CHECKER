How to Connect Google Sheets (2-Minute Setup)

  1. Create a new Google Sheet:

    Visit sheets.new and name it "CrediPulse Loan Records".

  2. Open Apps Script:

    Click Extensions > Apps Script in the top menu.

  3. Paste the Code:

    Replace any existing code with the ready-made script from google-sheets/Code.gs (provided in this project).

  4. Deploy as Web App:

    Click Deploy > New deployment. Select type "Web app". Set "Who has access" to "Anyone". Click Deploy.

  5. Paste Web App URL:

    Copy the generated Web App URL and paste it into the CrediPulse Settings modal. Done!
